# Arrowless

A tiny Windows 10/11 system tray app that removes the arrow overlay from shortcut icons.

## Installation (users)

1. Go to the **Releases** section of this repository and download `Arrowless-win-x64.zip`.
2. Unzip it and run `Arrowless.exe`. No installer and no .NET installation required.
3. A tray icon appears next to the clock (it may be inside the `^` overflow menu).

Windows SmartScreen may show a warning because the executable is not code-signed: click "More info" > "Run anyway". If you would rather not trust a prebuilt binary, build it yourself (see below).

**Compatibility:** developed and tested on Windows 11. Windows 10 should work too (it uses the same registry mechanism) but has not been tested.

## Usage

- Arrows are **hidden** by default.
- Right-click the tray icon:
  - **Show arrows**: toggles the arrows on/off.
  - **Start with Windows**: automatic startup (enabled on first run).
  - **Exit**.
- Every change asks for administrator confirmation (UAC) and restarts Windows Explorer for a few seconds.
- On startup the app checks the registry and recreates the value if it is missing (for example after a major Windows update).
- If a change fails, the tray icon shows a notification.

To uninstall: click "Show arrows", turn off "Start with Windows", exit the app and delete the exe. Optionally delete `HKCU\Software\Arrowless`.

## How it works

It writes the string value `29` under
`HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\Explorer\Shell Icons`
with the data `%windir%\System32\shell32.dll,-50`, a transparent icon that ships with Windows (no files are created).
It then refreshes the icon cache and restarts Explorer.

"Show arrows" deletes that value (only if it matches the one this app writes).

- The app runs with normal privileges. It only relaunches itself elevated (UAC) to touch HKLM (`--hide` / `--show`).
- User preferences are stored in `HKCU\Software\Arrowless`.
- It does not collect or send any data and uses no network.
- **Note:** if you already use another tool or a manual tweak that sets value `29` to something else (for example a custom arrow icon), Arrowless will overwrite it, and "Show arrows" will not bring your previous value back.

## Building (developers)

Requirements: the [.NET 8 SDK](https://dotnet.microsoft.com/download) on Windows.

```
dotnet build src/Arrowless -c Release
dotnet publish src/Arrowless -c Release -o publish   # single self-contained exe
```

The app icon is original and is generated by `tools/make-icon.ps1` (Windows PowerShell, no extra dependencies). Run it only if you want to change the design.

## Publishing a release

```
git tag v1.0.0
git push origin v1.0.0
```

The `.github/workflows/release.yml` workflow builds the exe and attaches a zip to the GitHub release.
